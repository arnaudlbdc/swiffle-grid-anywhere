# Swiffle Grid, anywhere

The live demo of [Swiffle Grid](https://wordpress.org/plugins/swiffle-grid-embed-data-anywhere/) on a site **without WordPress**: plain HTML pages hosted on GitHub Pages, at https://anywhere.swiffle-grid.com.

Every grid is a `<swiffle-grid>` tag plus one script line, served by the WordPress site https://demo.swiffle-grid.com, which allows these page addresses.

The pages are generated by `_build.py` from `_grids.json` (the grid settings copied from the demo site).

Ne jamais modifier directement index.html ni les index.html des sous-dossiers : le programme les réécrit à chaque lancement et la modification serait perdue.

Dans le modèle, les repères {{...}}

Dans _template/page.html, les mots entre doubles accolades sont remplacés automatiquement pour chaque page : {{TITLE}} (titre), {{INTRO}} (phrase d'intro), {{NAV}} (menu), {{BUTTONS}} (boutons WordPress, CodePen, Google Site, source), {{DATAK}} (la grille), {{SNIPPET}} (le code à coller). Tout le reste est du HTML ordinaire, modifiable librement.

Lancer le programme

Dans un terminal ouvert dans le dossier : python _build.py. Il affiche « ok 6 pages ».

Publier

Le site est publié par GitHub Pages depuis le dépôt public arnaudlbdc/swiffle-grid-anywhere, sous l'identité d'Arnaud :

git add -A
git -c user.name=Arnaud -c user.email=arnaud.lbdc@proton.me commit -m "…"
gh auth switch -u arnaudlbdc puis gh auth setup-git
git push
gh auth switch -u nicolasflbdc (pour revenir au compte habituel)

La mise en ligne prend une à deux minutes.

Les fichiers dont le nom commence par « _ » (ce document, le programme, le modèle, les listes) ne sont pas publiés sur le site.
